# 开发笔记

## 踩过的坑

### 1. 骨架归一化的"原点漂移"

- **问题**：用全局髋部中心做归一化时，相机抖动导致原点漂移
- **解决**：用**当前帧**的髋部中心，而非全局平均
- **代码**：`src/preprocess.py:normalize_skeleton`

### 2. LSTM 训练时 NaN

- **问题**：损失突然变 NaN
- **原因**：学习率太大，梯度爆炸
- **解决**：
  - 降低学习率（1e-3 → 5e-4）
  - 加 `torch.nn.utils.clip_grad_norm_`
  - 检查输入数据是否有 NaN

### 3. 类别不平衡

- **问题**：跌倒样本远少于正常活动
- **原因**：真实场景中跌倒本就稀少
- **解决**：
  - 合成数据增强（`src/generate_synthetic.py`）
  - `CrossEntropyLoss(weight=...)` 加权
  - Focal Loss

### 4. 时序对齐

- **问题**：滑窗采样时窗口边界正好在跌倒动作中间
- **解决**：滑窗 + 标签在窗口内多数投票

## 性能优化

- **模型量化**：`torch.quantization` 把 FP32 转 INT8，速度 ×2
- **ONNX Runtime**：比原生 PyTorch 推理快 1.5x
- **TensorRT**（NVIDIA）：Jetson 上可达 100+ FPS

## 真实部署经验

- **延迟要求**：< 200ms 才有"实时感"
- **误报成本**：养老院场景下，1 次/天的误报可接受
- **隐私**：不在云端留视频，仅上传告警事件
